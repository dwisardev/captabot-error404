# Diagramas del proyecto

Cada diagrama está en dos formatos: `.drawio` para editarlo en [draw.io](https://app.diagrams.net)
(Archivo → Abrir desde → Dispositivo) y `.png` para insertarlo en los informes.

| Diagrama | Archivo | Tarea en Jira |
|---|---|---|
| Casos de uso | `casos-de-uso` | SCRUM-31 |
| Arquitectura | `arquitectura` | SCRUM-32 |
| Modelo entidad-relación | `modelo-entidad-relacion` | SCRUM-33 |
| Flujo del asistente | `flujo-asistente` | SCRUM-38 |

Si cambian un diagrama en draw.io, exporten de nuevo el PNG con **Archivo → Exportar como → PNG**
(zoom 200 %) y suban ambos archivos en el mismo commit.
